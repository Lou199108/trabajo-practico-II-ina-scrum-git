# Trabajo Práctico II - Prácticas Profesionalizantes I

## 📋 Descripción general del proyecto
Este proyecto forma parte de las actividades prácticas de la **Tecnicatura Superior en Ciencia de Datos e Inteligencia Artificial** en el Instituto Nuevos Aires[cite: 1]. Consiste en la implementación de un modelo de aprendizaje automático supervisado de **Clasificación** utilizando el algoritmo de **Regresión Logística**. El objetivo principal es predecir la fuga de clientes (*churn*) en una compañía de telecomunicaciones a partir del análisis del dataset `telco_Customer_Churn.csv`.

## ⚙️ Tecnologías utilizadas
* **Lenguaje:** Python 3.x
* **Librerías de Ciencia de Datos y Machine Learning:** 
  * `Pandas` (para la carga, limpieza y manipulación de datos tabulares)
  * `Scikit-learn` (para la construcción del pipeline, preprocesamiento con `StandardScaler`, entrenamiento del modelo y métricas de evaluación)[cite: 7]
* **Control de versiones:** Git y GitHub
* **Entorno de desarrollo:** Visual Studio Code y Git Bash
